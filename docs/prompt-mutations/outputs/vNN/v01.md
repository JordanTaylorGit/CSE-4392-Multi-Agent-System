The State pattern can replace the `switch` statements by encapsulating the behavior of each operating mode (`OFF`, `COOL`, and `HEAT`) into separate state classes.

The `SeasonSwitch` class will maintain a reference to the current state and delegate operations to it.

## 1. State interface

Create an interface that defines the operations supported by each state.

java

```java
package cse4392;

public interface SeasonState {
    void cool();
    void heat();
    void off();
    void timerOff();
    void roomTick();
}
```

## 2. OffState class

When the system is OFF, requesting cooling or heating activates the corresponding equipment. Calling `off()` or `timerOff()` has no effect.

java

```java
package cse4392;

public class OffState implements SeasonState {
    private final SeasonSwitch system;

    public OffState(SeasonSwitch system) {
        this.system = system;
    }

    @Override
    public void cool() {
        system.ac.on();
        system.timer.start();
        system.setState(system.coolState);
        System.out.println("Cooling started. RmTemp=" + system.room.temp);
    }

    @Override
    public void heat() {
        system.heater.on();
        system.timer.start();
        system.setState(system.heatState);
        System.out.println("Heating started. RmTemp=" + system.room.temp);
    }

    @Override
    public void off() {
        // Already off.
    }

    @Override
    public void timerOff() {
        // Nothing to regulate.
    }

    @Override
    public void roomTick() {
        // Temperature does not change when the system is off.
    }
}
```

## 3. CoolState class

This state handles cooling operations and transitions to heating or OFF when requested.

java

```java
package cse4392;

public class CoolState implements SeasonState {
    private final SeasonSwitch system;

    public CoolState(SeasonSwitch system) {
        this.system = system;
    }

    @Override
    public void cool() {
        // Already cooling.
    }

    @Override
    public void heat() {
        system.ac.off();
        system.heater.on();
        system.timer.start();
        system.setState(system.heatState);
        System.out.println("Heating started. RmTemp=" + system.room.temp);
    }

    @Override
    public void off() {
        system.ac.off();
        system.timer.stop();
        system.setState(system.offState);
        System.out.println("Cooling stopped. RmTemp=" + system.room.temp);
    }

    @Override
    public void timerOff() {
        if (system.room.temp > system.coolTemp) {
            system.ac.on();
            System.out.println("Cooling started. RmTemp=" + system.room.temp);
        } else {
            system.ac.off();
            System.out.println("Cooling stopped. RmTemp=" + system.room.temp);
        }
    }

    @Override
    public void roomTick() {
        if (system.ac.isOn) {
            system.room.temp--;
        } else {
            system.room.temp++;
        }
    }
}
```

## 5. Refactored SeasonSwitch class

The main class no longer needs integer state constants or switch statements. Instead, it delegates all state-dependent behavior to the current state object.

java

```java
package cse4392;

import javax.swing.Timer;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.util.concurrent.CountDownLatch;

public class SeasonSwitch implements ActionListener {

    AC ac = new AC();
    Heater heater = new Heater();
    Room room = new Room();

    Timer timer = new Timer(1200, this);

    int coolTemp = 68;
    int heatTemp = 77;

    // State objects
    final SeasonState offState = new OffState(this);
    final SeasonState coolState = new CoolState(this);
    final SeasonState heatState = new HeatState(this);

    // Initial state
    private SeasonState currentState = offState;

    public void setState(SeasonState state) {
        currentState = state;
    }

    public void cool() {
        currentState.cool();
    }

    public void heat() {
        currentState.heat();
    }

    public void off() {
        currentState.off();
    }

    public void timerOff() {
        currentState.timerOff();
    }

    public void roomTick() {
        currentState.roomTick();
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        timerOff();
    }

    public static void main(String[] args) {

        System.out.println("Enter off, cool or heat to run. " +
                "Press Ctrl-c to exit.");

        SeasonSwitch s = new SeasonSwitch();

        s.room.timer.start();

        if (args.length == 0) {
            s.cool();
        } else if ("off".equals(args[0])) {
            s.off();
            System.out.println("System off. System exits.");
            System.exit(0);
        } else if ("cool".equals(args[0])) {
            s.cool();
        } else if ("heat".equals(args[0])) {
            s.heat();
        } else {
            System.out.println("Unknown command. System exits.");
            System.exit(1);
        }

        try {
            new CountDownLatch(5).await();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            s.timer.stop();
            s.room.timer.stop();
        }
    }
}
```

## 6. Refactored AC, Heater, and Room classes

These classes can remain simple. The important change is that `Room` delegates temperature changes to the current state instead of using a switch statement.

AC.java

java

```java
package cse4392;

public class AC {
    boolean isOn = false;

    public void on() {
        isOn = true;
    }

    public void off() {
        isOn = false;
    }
}
```

Heater.java

java

```java
package cse4392;

public class Heater {
    boolean isOn = false;

    public void on() {
        isOn = true;
    }

    public void off() {
        isOn = false;
    }
}
```

Room.java

java

```java
package cse4392;

import javax.swing.Timer;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class Room implements ActionListener {

    public int temp = 70;

    Timer timer = new Timer(400, this);

    @Override
    public void actionPerformed(ActionEvent ae) {
        // Delegate temperature behavior to the current state.
        SeasonSwitch.thisInstance.roomTick();
    }
}
```

There is one correction needed in this last class: the original design has `Room` as an inner class of `SeasonSwitch`, so it can access the enclosing instance. Keep it as a non-static inner class inside `SeasonSwitch`, or use the following constructor-based approach if you want separate files.

For separate files, use:

java

```java
package cse4392;

import javax.swing.Timer;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class Room implements ActionListener {

    public int temp = 70;
    private final SeasonSwitch system;

    Timer timer;

    public Room(SeasonSwitch system) {
        this.system = system;
        timer = new Timer(400, this);
    }

    @Override
    public void actionPerformed(ActionEvent ae) {
        system.roomTick();
    }
}
```

Then change the `SeasonSwitch` field initialization to:

java

```java
Room room = new Room(this);
```

## 8. Benefits of this refactoring

- Eliminates switch statements: State-dependent logic is moved into individual state classes.
- Encapsulation: Each state controls its own behavior and transitions.
- Easier maintenance: Adding another state (for example, AUTO) requires a new state class rather than modifying multiple switch statements.
- Follows the Open/Closed Principle: Existing state classes can remain unchanged when adding new state behavior.
- Cleaner SeasonSwitch: The context delegates operations to the active state.

Important: The original behavior is preserved: the AC and heater cycle on and off according to the room temperature thresholds, and the room temperature changes according to the active state.
