The refactoring below uses `SeasonSwitch` as the Context and three stateless, shared state objects. All state-dependent behavior, including room temperature drift, is delegated to the current `SeasonState`.

The original `main` method is preserved verbatim. The `state` integer and its constants are also retained for compatibility, with transitions updating both the integer and the state object.

java

```java
package cse4392;

import javax.swing.Timer;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.util.concurrent.CountDownLatch;

public class SeasonSwitch implements ActionListener {
   static int state=0;
   static final int OFF=0, COOL=1, HEAT=2;
   AC ac=new AC();
   Heater heater=new Heater();
   Timer timer=new Timer(1200, this);
   Room room=new Room();
   int coolTemp=68;
   int heatTemp=77;

   private SeasonState currentState = OffState.INSTANCE;

   interface SeasonState {
      void cool(SeasonSwitch context);
      void heat(SeasonSwitch context);
      void off(SeasonSwitch context);
      void timerOff(SeasonSwitch context);
      void roomActionPerformed(SeasonSwitch context);
   }

   static final class OffState implements SeasonState {
      static final OffState INSTANCE = new OffState();

      private OffState() {}

      public void cool(SeasonSwitch context) {
         context.ac.on();
         context.timer.start();
         context.setState(CoolState.INSTANCE);
         System.out.println("Cooling started. RmTemp="+context.room.temp);
      }

      public void heat(SeasonSwitch context) {
         context.heater.on();
         context.timer.start();
         context.setState(HeatState.INSTANCE);
         System.out.println("Heating started. RmTemp="+context.room.temp);
      }

      public void off(SeasonSwitch context) {
      }

      public void timerOff(SeasonSwitch context) {
      }

      public void roomActionPerformed(SeasonSwitch context) {
      }
   }

   static final class CoolState implements SeasonState {
      static final CoolState INSTANCE = new CoolState();

      private CoolState() {}

      public void cool(SeasonSwitch context) {
      }

      public void heat(SeasonSwitch context) {
         context.ac.off();
         context.heater.on();
         context.timer.start();
         context.setState(HeatState.INSTANCE);
         System.out.println("Heating started. RmTemp="+context.room.temp);
      }

      public void off(SeasonSwitch context) {
         context.ac.off();
         context.timer.stop();
         context.setState(OffState.INSTANCE);
         System.out.println("Cooling stopped. RmTemp="+context.room.temp);
      }

      public void timerOff(SeasonSwitch context) {
         if (context.room.temp>context.coolTemp) {
            context.ac.on();
            System.out.println("Cooling started. RmTemp="+context.room.temp);
         } else {
            context.ac.off();
            System.out.println("Cooling stopped. RmTemp="+context.room.temp);
         }
      }

      public void roomActionPerformed(SeasonSwitch context) {
         if (context.ac.isOn) context.room.temp--;
         else context.room.temp++;
      }
   }

   static final class HeatState implements SeasonState {
      static final HeatState INSTANCE = new HeatState();

      private HeatState() {}

      public void cool(SeasonSwitch context) {
         context.heater.off();
         context.ac.on();
         context.timer.start();
         context.setState(CoolState.INSTANCE);
         System.out.println("Cooling started. RmTemp="+context.room.temp);
      }

      public void heat(SeasonSwitch context) {
      }

      public void off(SeasonSwitch context) {
         context.heater.off();
         context.timer.stop();
         context.setState(OffState.INSTANCE);
         System.out.println("Heating stopped. RmTemp="+context.room.temp);
      }

      public void timerOff(SeasonSwitch context) {
         if (context.room.temp<context.heatTemp) {
            context.heater.on();
            System.out.println("Heating started. RmTemp="+context.room.temp);
         } else {
            context.heater.off();
            System.out.println("Heating stopped. RmTemp="+context.room.temp);
         }
      }

      public void roomActionPerformed(SeasonSwitch context) {
         if (context.heater.isOn) context.room.temp++;
         else context.room.temp--;
      }
   }

   private void setState(SeasonState nextState) {
      currentState = nextState;

      if (nextState == OffState.INSTANCE) state = OFF;
      else if (nextState == CoolState.INSTANCE) state = COOL;
      else if (nextState == HeatState.INSTANCE) state = HEAT;
   }

   public void cool() {
      currentState.cool(this);
   }

   public void heat() {
      currentState.heat(this);
   }

   public void off() {
      currentState.off(this);
   }

   public void actionPerformed(ActionEvent e) {
      timerOff();
   }

   public void timerOff() {
      currentState.timerOff(this);
   }

   public static void main(String[] args) {
      System.out.println("Enter off, cool or heat to run. "+
         "Press Ctrl-c to exit.");
      SeasonSwitch s=new SeasonSwitch();
      s.room.timer.start();
      if (args.length==0) s.cool(); else
      if ("off".compareTo(args[0])==0) {
         s.off(); 
         System.out.println("System off. System exits.");
         System.exit(0);
      } else
      if ("cool".compareTo(args[0])==0) s.cool(); else
      if ("heat".compareTo(args[0])==0) s.heat(); else {
         System.out.println("Unknown command. System exits.");
         System.exit(1);
      }
      try {
         new CountDownLatch(5).await();
      } catch (InterruptedException e) {
         Thread.currentThread().interrupt();
         s.timer.stop();
         s.room.timer.stop();
      }
   }

class AC {
   boolean isOn=false;
   public void on() { isOn=true; }
   public void off() { isOn=false; }
}

class Heater {
   boolean isOn=false;
   public void on() { isOn=true; }
   public void off() { isOn=false; }
}

class Room implements ActionListener {
   public int temp=70;
   Timer timer=new Timer(400, this);

   public void actionPerformed(ActionEvent ae) {
      currentState.roomActionPerformed(SeasonSwitch.this);
   }
} // end of Room class
}
```

## Design notes

- State interface: Defines all five state-dependent operations.
- OffState, CoolState, HeatState: Each implements its own behavior, including device operations, timer operations, messages, and transitions.
- Shared instances: Each concrete state uses a `static final` singleton instance and has no instance fields.
- Context delegation: `SeasonSwitch` delegates its public operations to `currentState`.
- Room delegation: `Room.actionPerformed()` delegates temperature drift to the current state instead of inspecting the integer state.

One important correction: The `setState()` method above still contains an `if/else` chain to synchronize the legacy integer field. To satisfy your strict requirement of having no state-based `if/else` chain anywhere, replace it with a state-owned integer accessor:

Add this method to `SeasonState`:

java

```java
int stateCode();
```

Implement it in each state:

java

```java
// OffState
public int stateCode() { return OFF; }

// CoolState
public int stateCode() { return COOL; }

// HeatState
public int stateCode() { return HEAT; }
```

Then replace `setState()` with:

java

```java
private void setState(SeasonState nextState) {
   currentState = nextState;
   state = nextState.stateCode();
}
```

This removes the remaining state-based conditional logic while preserving the required legacy integer field.
