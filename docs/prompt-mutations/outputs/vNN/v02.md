The refactoring below introduces a `SeasonState` interface with three concrete states: `OffState`, `CoolState`, and `HeatState`.

The existing public methods delegate to the current state. The original hardware operations, timer operations, state transitions, temperature checks, and print statements retain their original ordering and behavior.

java

```java
package cse4392;

import javax.swing.Timer;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.util.concurrent.CountDownLatch;

public class SeasonSwitch implements ActionListener {
   static int state=0;
   static final int OFF=0, COOL=1, HEAT=2;
   AC ac=new AC();
   Heater heater=new Heater();
   Timer timer=new Timer(1200, this);
   Room room=new Room();
   int coolTemp=68;
   int heatTemp=77;

   private interface SeasonState {
      void cool();
      void heat();
      void off();
      void timerOff();
   }

   private final SeasonState offState = new OffState();
   private final SeasonState coolState = new CoolState();
   private final SeasonState heatState = new HeatState();

   private SeasonState currentState = offState;

   private void transitionTo(SeasonState newState, int newValue) {
      currentState = newState;
      state = newValue;
   }

   private class OffState implements SeasonState {
      public void cool() {
         ac.on();
         timer.start();
         transitionTo(coolState, COOL);
         System.out.println("Cooling started. RmTemp="+room.temp);
      }

      public void heat() {
         heater.on();
         timer.start();
         transitionTo(heatState, HEAT);
         System.out.println("Heating started. RmTemp="+room.temp);
      }

      public void off() {
      }

      public void timerOff() {
      }
   }

   private class CoolState implements SeasonState {
      public void cool() {
      }

      public void heat() {
         ac.off();
         heater.on();
         timer.start();
         transitionTo(heatState, HEAT);
         System.out.println("Heating started. RmTemp="+room.temp);
      }

      public void off() {
         ac.off();
         timer.stop();
         transitionTo(offState, OFF);
         System.out.println("Cooling stopped. RmTemp="+room.temp);
      }

      public void timerOff() {
         if (room.temp>coolTemp) {
            ac.on();
            System.out.println("Cooling started. RmTemp="+room.temp);
         } else {
            ac.off();
            System.out.println("Cooling stopped. RmTemp="+room.temp);
         }
      }
   }

   private class HeatState implements SeasonState {
      public void cool() {
         heater.off();
         ac.on();
         timer.start();
         transitionTo(coolState, COOL);
         System.out.println("Cooling started. RmTemp="+room.temp);
      }

      public void heat() {
      }

      public void off() {
         heater.off();
         timer.stop();
         transitionTo(offState, OFF);
         System.out.println("Heating stopped. RmTemp="+room.temp);
      }

      public void timerOff() {
         if (room.temp<heatTemp) {
            heater.on();
            System.out.println("Heating started. RmTemp="+room.temp);
         } else {
            heater.off();
            System.out.println("Heating stopped. RmTemp="+room.temp);
         }
      }
   }

   public void cool() {
      currentState.cool();
   }

   public void heat() {
      currentState.heat();
   }

   public void off() {
      currentState.off();
   }

   public void actionPerformed(ActionEvent e) {
      timerOff();
   }

   public void timerOff() {
      currentState.timerOff();
   }

   public static void main(String[] args) {
      System.out.println("Enter off, cool or heat to run. "+
         "Press Ctrl-c to exit.");
      SeasonSwitch s=new SeasonSwitch();
      s.room.timer.start();
      if (args.length==0) s.cool(); else
      if ("off".compareTo(args[0])==0) {
         s.off(); 
         System.out.println("System off. System exits.");
         System.exit(0);
      } else
      if ("cool".compareTo(args[0])==0) s.cool(); else
      if ("heat".compareTo(args[0])==0) s.heat(); else {
         System.out.println("Unknown command. System exits.");
         System.exit(1);
      }
      try {
         new CountDownLatch(5).await();
      } catch (InterruptedException e) {
         Thread.currentThread().interrupt();
         s.timer.stop();
         s.room.timer.stop();
      }
   }

   class AC {
      boolean isOn=false;
      public void on() { isOn=true; }
      public void off() { isOn=false; }
   }

   class Heater {
      boolean isOn=false;
      public void on() { isOn=true; }
      public void off() { isOn=false; }
   }

   class Room implements ActionListener {
      public int temp=70;
      Timer timer=new Timer(400, this);

      public void actionPerformed(ActionEvent ae) {
         switch (state) {
            case OFF: return;
            case COOL:
               if (ac.isOn) temp--; else temp++;
               break;
            case HEAT:
               if (heater.isOn) temp++; else temp--;
               break;
         }
      }
   } // end of Room class
}
```

### Design notes

- State pattern: Each concrete state implements `SeasonState` and defines its own response to `cool()`, `heat()`, `off()`, and `timerOff()`.
- State transitions: `transitionTo()` updates both the state object and the existing static `state` integer.
- Compatibility: The original constants, fields, inner classes, and method signatures are retained.
- No duplicated transition logic: The public methods simply delegate to the current state.

Important: The original `static state` field is shared across all `SeasonSwitch` instances, whereas `currentState` is instance-specific. This implementation preserves the original single-instance behavior, but multiple instances could become inconsistent. For strict multi-instance compatibility, the state object would need to be synchronized with the shared static state.
